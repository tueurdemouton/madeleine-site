Bêta · version 1.0.3

Sur Android

Installez directement l’application sur votre téléphone.

Télécharger pour Android ↓

Fichier APK · environ 44 Mo

  1. Téléchargez le fichier. Si le navigateur demande une confirmation, vérifiez que vous êtes sur madeleine-de-gout.com, puis confirmez le téléchargement.
  2. Ouvrez le téléchargement. Retrouvez-le dans la notification ou dans Fichiers → Téléchargements.
  3. Autorisez l’installation si nécessaire. Android peut demander d’autoriser votre navigateur à installer cette application. Validez uniquement si vous souhaitez installer la bêta.
  4. Installez, puis ouvrez Madeleine. Choisissez « Commencer » pour créer votre compte ou « Se connecter » si vous en avez déjà un.
Comment mettre l’application à jour ?

Revenez sur cette page et installez la nouvelle version par-dessus l’ancienne, sans désinstaller Madeleine.

Bêta · avec TestFlight

Sur iPhone

Apple utilise TestFlight pour installer les applications en cours de test. L’installation de TestFlight n’est nécessaire qu’une fois.

La bêta iPhone est ouverte. Installez TestFlight, puis rejoignez la bêta Madeleine en deux gestes.

1. Installer TestFlight ↗2. Rejoindre la bêta Madeleine ↗

Vous avez déjà TestFlight ? Passez directement à l’étape 2.

  1. Installez TestFlight depuis l’App Store. C’est l’application de test d’Apple.
  2. Revenez ici et ouvrez le lien de la bêta. Dans TestFlight, touchez « Accepter », puis « Installer » lorsque la version est disponible.
  3. Ouvrez Madeleine. Créez votre propre compte ou connectez-vous. Vous pourrez ensuite ouvrir l’application depuis son icône habituelle.
Et les prochaines mises à jour ?

TestFlight vous préviendra quand une nouvelle version sera disponible. Vous pouvez activer les mises à jour automatiques dans TestFlight.

Un petit coup de main ?

Le lien s’ouvre mal depuis WhatsApp

Utilisez le menu de la page pour ouvrir le lien dans Safari sur iPhone, ou dans votre navigateur habituel sur Android. Vous pouvez aussi copier le lien affiché ci-dessus et le coller dans ce navigateur.

Je n’arrive pas à rejoindre la bêta sur iPhone

Vérifiez que TestFlight est installé, puis rouvrez le lien « Rejoindre la bêta Madeleine » depuis Safari. L’app nécessite iOS 18.2 ou une version ultérieure.

Pour signaler un souci, écrivez à paul@madeleine-de-gout.com. Indiquez votre téléphone et ce qui se passe à l’écran, sans envoyer de mot de passe.
