Installer la bêta

Version 1.0 (bêta) — novembre 2026

Sur Android

Télécharger l'application (40 Mo)

  1. Touche le bouton ci-dessus depuis ton téléphone Android. Le navigateur peut prévenir que ce type de fichier « peut être dangereux » : c'est le message habituel pour toute application installée hors du Play Store. Touche Télécharger quand même.
  2. Ouvre le fichier téléchargé (dans la notification, ou dans l'application Fichiers → Téléchargements).
  3. La première fois, Android demande d'autoriser ton navigateur à installer des applications : touche Paramètres, active Autoriser cette source, puis reviens en arrière.
  4. Touche Installer, puis Ouvrir.
  5. Dans l'application : J'ai déjà un compte → Continuer avec Google, ou Commencer pour répondre aux questions et créer ton compte à la fin.

Les mises à jour se font de la même façon : télécharge la nouvelle version ici et installe-la par-dessus, tes données sont gardées.
